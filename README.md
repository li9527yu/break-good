# break-good · 地下班次

在支持 WebGL 2 的浏览器中打开 `game.html`。游戏包含完整的章节流程、分支与结局，运行所需的脚本和素材都在此目录，可以离线游玩。

游戏会在当前浏览器自动存档。如果旧试玩的进度没有自动出现在新目录，请在旧版的「菜单」里导出存档，再到新版导入。正在操作但尚未提交的实验批次会在刷新后重新开始。

| 路径 | 内容 |
| --- | --- |
| `game.html` | 主游戏入口 |
| `workbench-2d.html` | 反应罐页面，由主游戏嵌入，也可以单独打开 |
| `game/` | 剧情、事件状态机、存档、工作台与界面 |
| `game/three/` | 三维实验室、人物行为、通道和反应罐源码 |
| `assets/` | 游戏所用的角色肖像与物品图标 |
| `vendor/` | 离线运行脚本和第三方许可证 |

需要修改三维源码时，在此目录安装依赖并重建。旧版实验的事件解码逻辑保留在 `game/lab.js`，用于重放已有存档。

```sh
npm ci
npm run build
npm test
```
